# Carrito de Compras con Local Storage

Este proyecto es una implementación básica de un carrito de compras utilizando JavaScript y Local Storage del navegador.

## Objetivo

Aprender a almacenar, recuperar y manipular datos en el navegador para simular el comportamiento de un carrito de compras sin necesidad de backend.

## Funcionalidades

- Agregar productos al carrito
- Aumentar la cantidad de productos
- Mostrar productos en el carrito
- Calcular el total a pagar
- Persistencia de datos con Local Storage

## Tecnologías utilizadas

- HTML
- CSS (opcional)
- JavaScript (Vanilla)
